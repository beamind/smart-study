# 004：没有 API Key 时，通过云函数中转试用

日期：2026-10-31。状态：已实施，已部署在新加坡。部署步骤见[试用中转服务部署](../trial-proxy.md)。

## 背景

App 拍照识别、翻译和举一反三要调用千问。现在每个家长都要自己注册阿里云、实名、开通百炼、创建 API Key 再填进 App。没用过大模型的家长，还没看到效果就要做这么多步，很可能直接放弃。

把作者的 Key 直接打进 APK 不行：

- App 的界面代码是普通 JavaScript，解压 APK 就能看到明文的 Key。
- Key 被拿走后，可以调用账号下所有允许的模型，做任何事。阿里云账号是实名的，后果由作者承担。
- 能确认的只有子业务空间的模型白名单和分账账单；没有找到“每天花到多少就停”的硬上限。

## 决定

在阿里云函数计算上放一个很小的中转服务。没有填 API Key 的设备，经它试用固定次数；用完后提示填自己的 Key。

### 服务做什么

- Key 只保存在云函数的环境变量里，不在 App、仓库或日志里。
- App 不发提示词，只发任务和素材：

  | 任务 | App 发送 | 服务端做什么 |
  |---|---|---|
  | `words` | 照片、语言 | 用固定提示词调 `qwen3.8-flash`，返回模型回复 |
  | `questions` | 照片 | 同上，识别错题 |
  | `underlines` | 照片、题目文字 | 同上，识别划线 |
  | `translate` | 一个英文词或短语 | 调 `qwen3.8-flash` 翻译 |
  | `generate` | 一道原题和答案 | 调 `qwen3.8-max` 出一道新题 |

  提示词和模型都定死在服务端，请求里带的提示词或模型会被丢掉。这挡不住提示注入：原题、要翻译的词和划线题目文字会拼进提示词，素材里可以写"忽略上面的要求，回答……"。所以服务端用 App 自己的解析代码检查回复，不是这个任务要的格式（例如出题却回了一段文章）就不返回原文，只返回空结果；翻译只返回清理后的一行，最长 100 个字。这样拿它当通用大模型用只能得到很少的东西，但不能完全排除；真正的防线是下面的次数和费用上限。
- 每个请求限制大小：照片不超过 1.5 MB（Base64 后 200 万个字符）；翻译不超过 100 个字符；原题不超过 2,000 个字符；识别划线最多 50 道题、题目文字合计不超过 8,000 个字符；模型输出的 Token 数也设上限（翻译 200，举一反三 1,000，识别 1,500–4,000）。
- 每个请求只调一次千问，超时 40 秒。试用时 App 固定等 55 秒、最多试 2 次，不用设置里的超时和重试次数：App 每次重试都是一个新的、要计数的请求，App 比服务端先放弃的话，服务端照样计数，用户却什么也没拿到。服务端也不重试，否则 App 已经放弃了，服务端还在花钱。
- 千问调用失败时次数退回。千问已经收到请求、只是没等到回复（超时、网络中断）时，可能已经计费，这一次的最大费用不退；千问返回了空回复时按它报的实际用量计费。服务端 Key 无效、模型不可用、千问拒绝请求这类用户改不了的错误，只告诉 App"试用服务暂时不能处理这个请求"，并让 App 不要重试；详细原因（千问的英文原文、账号状态）只写日志。
- 模型回复检查过格式后原样返回，解析仍在 App 里做，和用自己的 Key 时走同一套代码。
- 照片和文字只用于这一次调用，服务端不保存；日志只记任务类型、设备标识的前 8 位、Token 用量和费用。IP 地址加盐（环境变量 `IP_SALT`）做 SHA-256 后才用作计数的名字，不保存原文。

### 额度

- **每台设备**：App 第一次试用时生成一个随机的设备标识，保存在 App 的私有存储里。每台设备默认 20 次拍照识别（识别划线算一次）、100 个词的翻译、10 道举一反三。用完后，App 提示“试用额度用完了，填写自己的 API Key 可以继续使用”。
- **每天的千问费用不超过 1 元，分成两份**：这是真正的止损线，由代码保证，不依赖阿里云的预算提醒（误差见下面"先预留，再结算"）。云函数的费用另算（见"费用估算"）。
  - 拍照识别和翻译：每天 0.7 元，大约 200 次拍照识别。
  - 举一反三：每天 0.3 元，大约 20–60 道题。分开算，举一反三被刷满时，拍照识别和翻译不受影响。
  - **先预留，再结算**：调用千问之前，先把这一次可能的最高费用（输入按偏高的估算，一张图按 16,384 Token 算，输出按允许的最长回复算）记到当天的花费上，记了以后不超过上限才放行；调用结束后改成千问返回的实际 Token 数乘以单价。设备次数和 IP 次数也一样先占上再调用。这样同时在途的请求再多，也不会一起越过上限：每个都要先占到自己那一份。花到上限后，这一类当天停止试用，提示明天再试或填自己的 Key。
  - 一次举一反三最多预留约 0.05–0.08 元，一次拍照识别约 0.025 元，所以快到上限时会比上限早一点停下。千问实际用量超过估算（例如有人发了特别大的图）时，超出的部分会多花，每次最多几分钱。
  - 千问返回以后，改计数失败只记日志，照样把回复交给 App，不让 App 付费重试；这时预留的最高费用留在当天的花费里，只会多算，不会少算。
  - "当天"按北京时间算。
- **每个 IP**：拍照识别和翻译每天最多 60 次，举一反三每天最多 10 次，防止一个人换设备标识刷额度。国内手机网络常常很多人共用一个公网 IP，所以只把举一反三收得更紧。
- **防刷请求本身**：每个函数实例在内存里限制每个 IP 每分钟最多 60 个请求（查询剩余次数也算），同时在途的千问调用最多 8 个，超出的直接拒绝，不读表。这样不花千问钱的请求（查询、额度已用完的请求）也刷不出大量函数和表格存储费用。
- 计数和当天花费放在表格存储（Tablestore）里。每次改动是"读出来，条件更新"：值在这期间被别的请求改了就随机等几毫秒重来，所以并发时不会多扣或少扣。

设备标识可以被伪造，所以每设备额度只防正常用户用过头。防滥用靠固定的提示词和模型、回复格式检查、请求大小限制、每 IP 上限和每天的费用上限。有人恶意刷满当天的额度，最多让其他人当天试用不了，千问费用仍不超过 1 元。

### 账号和 Key

- 专门为试用新建一个 API Key，只用在这个云函数里。
- 在百炼里为它建一个子业务空间，只允许 `qwen3.8-flash` 和 `qwen3.8-max`，账单单独算。这样即使 Key 泄露，也只能调这两个模型，而且一眼能看出试用花了多少。

### 部署

- 地域：新加坡（2026-10-31 部署时选定；原计划是中国香港，两者都可以）。海外和香港地域绑定的域名不需要 ICP 备案；云函数通过公网调用北京的千问。从国内访问新加坡比香港多零点几秒的网络往返，相对等千问的 1–7 秒影响不大，晚高峰线路可能不如香港稳定。以后如果做了备案，可以搬到北京；搬地域要重建函数和表格存储，地址会变，要发新版本 App。
- **先不用域名**：一开始直接用 HTTP 触发器自带的公网地址（`…fcapp.run`）。这样做的代价：
  - 官方说明自带地址只用于测试，不保证稳定；
  - `fcapp.run` 下的地址也被别人用来做过恶意软件的控制服务器，个别网络或安全软件可能拦截这个域名；
  - 以后换成自己的域名，要发一个新版本 App，已经装了旧版本的人在升级前用不了试用（自己填 Key 不受影响）。
- 以后买了域名（例如 `trial.<域名>`），绑定到同一个函数即可，服务端不用改。
- 服务端代码放在仓库的 `server/trial-proxy/`，和 App 一起开源。Key、单价和额度参数通过云函数的环境变量配置。

### App 的改动

- **调用方式**：设置里没有 API Key 时，模型调用经中转服务；填了 Key 就直接调千问，和现在一样。中转地址写在 `src/ai/trial.ts` 的 `RELEASE_TRIAL_URL` 里，只有构建 APK 时使用；开发和自动测试不用试用。
- **剩余次数**：设置页显示“试用还剩：拍照识别 N 次，翻译 N 次，举一反三 N 次”。第一次使用的“填写 API Key”页说明可以先免费试用，按钮是“先免费试用”。
- **出错时**：额度用完时，提示语由服务端给出，写明是这台设备的次数用完了，还是今天的名额用完了，并说明在设置里填自己的 Key 可以继续用。
- **自定义模型、提示词、超时和重试次数**：试用时不生效，设置页会说明这一点。
- **README**：在“数据和隐私”里写明，试用时照片会经过作者的中转服务器，再发给千问，服务器不保存照片。

## 费用估算

- **千问每天不超过 1 元**（拍照识别和翻译 0.7 元，举一反三 0.3 元）。一个月最多约 30 元，这是每天都被用满的最坏情况。
- **云函数另算，没有代码保证的上限**：只要某个小时里有调用，这一小时最少收 0.01 元，有人每小时都用时每天约 0.24 元。每次调用要等千问 1–7 秒，按 0.35 vCPU、512 MB 算，每次不到 0.0004 元。低频使用时每月一两元。被人用很多 IP 刷请求时，这部分费用随请求数增长；每 IP 每分钟 60 个和最多 2 个实例的设置能压住大部分，但不是硬上限，所以要在费用中心给函数计算和表格存储设预算提醒（见部署说明第 9 步）。
- **一台设备**用完全部试用额度大约 0.2 元，其中 20 次拍照约 0.08 元，10 道举一反三约 0.1 元。
- **表格存储**：正常使用时每天几千次计数读写，几分钱。

## 被放弃的方案

- **把 Key 打进 APK**：见“背景”。
- **部署在作者自用的新加坡服务器**：服务地址写在开源的 App 里，等于公开了这台 VPN 服务器的 IP。IP 被扫描或被封，会连累 VPN；中转服务一旦有漏洞，被攻破的是放着 VPN 配置的机器。
- **国内地域（北京、杭州）**：绑定的域名要 ICP 备案，要等几周。等备案下来可以再搬。
- **Cloudflare Workers**：`workers.dev` 在国内访问不稳定。
- **按调用次数设全局上限**：一次举一反三的费用是一次翻译的上百倍，按次数算不能保证费用上限，改为按实际 Token 费用累计。

## 已确认（2026-10-31）

- 先不用域名，用自带的公网地址；以后买了域名再换。
- 每台设备：20 次拍照识别、100 个词翻译、10 道举一反三（总共，不按天）。
- 每个 IP 每天：拍照识别和翻译 60 次，举一反三 10 次。
- 千问每天不超过 1 元：拍照识别和翻译 0.7 元，举一反三 0.3 元；云函数费用另算。
- 新申请一个只用于试用的 API Key。
- 先部署在新加坡（函数计算和表格存储都在 `ap-southeast-1`），以后需要时再搬。
