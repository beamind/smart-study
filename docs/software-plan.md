# 智能学习 软件说明

更新日期：2026-10-31。

给小学生用的听写和英语错题练习 App。孩子用手机或平板完成语文听写、英语听写和英语错题练习，家长能看到每个词、每道题的对错历史。拍照后由千问识别词语或题目，App 朗读、计时、记录对错，再根据错误率和间隔天数挑出需要复习的内容。同一套代码可以在电脑浏览器里使用和开发，也可以打包成 Android App。

技术选型见[架构决定 001](decisions/001-web-stack-without-voice-commands.md)，数据存储见[架构决定 002](decisions/002-public-documents-storage-via-saf.md)，签名见[架构决定 003](decisions/003-release-signing.md)，数据格式见[数据约定](data-contract.md)。

## 设备与安装

- 已在华为 MatePad 11（HarmonyOS 4.2，Android API 31）上使用；荣耀 Magic7 Pro（MagicOS 10 / Android 16）待实测。
- 数据保存在 `Documents/smartstudy`，卸载 App 不会丢失；重装后重新授权这个文件夹即可继续使用。
- 正式包的应用 ID 是 `com.smartstudy`。开发用的 debug 包是 `com.smartstudy.dev`，桌面名称同样是"智能学习"，可以和正式包同时安装。两者共用 `Documents/smartstudy` 的数据，但各自要授权文件夹、填写 API Key。

## 功能

| 功能 | 说明 |
|---|---|
| 语文听写 | 拍照、相册或手动输入词语 → 确认词表（可删除、修改、补充）→ 打乱顺序 → 每个词朗读两遍 → 点"下一个"或超时进入下一词，没听清可点"再读一遍" → 显示答案 → 点选写错的词并提交 |
| 英语听写 | 同上；可选"读中文写英文"或"读英文写英文"。开始前一次翻译完缺译文的词，优先用错词本里已有的译文；翻译失败时改读英文并提示 |
| 错词本 | 按语文、英语分别列出所有听写过的词（包括从没写错的）和"错误次数 / 总次数"；可搜索、筛选（全部 / 错过的 / 最近添加），添加、修改、批量删除整个词。改成已有的词时两者合并 |
| 错词听写 | 选择数量（5–40），从错词本的全部词中按错误率和间隔天数抽词，进入同样的听写流程 |
| 英语错题本：录入 | 拍照或选图 → 裁剪 → 识别题目，答案由模型给出（不是照片上孩子写的答案）→ 可选识别划线的字母或单词 → 修改、勾选后保存；也可以手动输入题目和答案 |
| 英语错题本：查看 | 列表显示题目、答案和错误次数 / 总次数；可搜索、筛选，修改题目和答案，批量删除整道题 |
| 错题练习 | 选择数量，按错误率和间隔天数抽题 → 逐题显示，每题限时 → 显示答案 → 点选仍然做错的题并提交 |
| 举一反三 | 抽取原题，每道原题由模型出一道考察相同知识点的新题（3 道同时出）→ 按练习流程完成 → 只把做错的新题保存到错题本。出题失败的题显示原因，可以单独重试 |
| 学习记录 | "按次"视图倒序列出每次听写、录入、练习和举一反三，可以查看、撤销，听写还可以"再听一遍"；"按词和题"视图汇总所选日期范围内的每个词或每道题，可以修改，删除时只删所选范围内的记录。顶部显示所选范围的汇总 |
| 用户 | 多个孩子分别记录；添加、改名、删除（算术确认）、切换 |
| 设置 | 千问 API Key、朗读语速、两遍间隔、单题限时（可设为不限时）、模型名称、提示词（高级） |
| 首次使用 | 授权数据文件夹 → 填写 API Key（可以以后再填）→ 创建第一个孩子 |

## 规则

- **一次提交是一次学习**：一次听写、一次错词听写、一次手动添加、一次错题录入、一次练习、一次举一反三，各记为一个 session，学习记录按 session 列出。
- **提交后可以撤销**：保存成功的提示里带"撤销"按钮；离开页面后，也可以在听写页"最近的听写"、错题本顶部"最近一次"或学习记录里找到这一次并撤销。撤销只删除这次的作答记录；这次新建的词或题如果因此没有任何记录，就一并删除。
- **录入错题时提示重复**：和错题本已有的题比较（忽略空格、标点、大小写和划线标记）。完全相同的标"已在错题本"，非常相似的标"可能重复"，并显示原来的录入时间；这两类题默认不勾选。
- **删除范围**：在错词本、错题本里删除，删的是整个词或整道题；在学习记录里删除，只删所选日期范围内的记录。删除前要做一道 10 以内的加减法确认。
- **中断后可恢复**：进行中的听写或练习被关闭，重新打开时可以从原题继续，或直接进入对答案。答案页还没提交就离开时会提醒。
- **暂停**：听写和练习可以暂停；App 切到后台时自动暂停朗读和计时。
- **防止连点**：提交按钮按下后立即禁用，直到保存完成。
- **抽样**：每个候选项的抽中概率是错误率和"间隔天数 × 0.01"中较大的一个，详见[数据约定](data-contract.md)。
- **数据安全**：每次用户操作只写一次文件；写入前先校验；每个文件保留历史版本。见[架构决定 002](decisions/002-public-documents-storage-via-saf.md)。

## 界面原则

- **一个页面一个主要动作**。例如听写进行中，屏幕上只显示进度"第 3 / 12 个"和剩余时间，底部是占满宽度的"下一个"按钮，旁边是较小的"再读一遍"和"暂停"。
- **孩子操作的按钮要大**。听写和练习中孩子按的按钮至少 64px 高，家长用的按钮至少 48px；家长才用的功能（编辑、删除、设置）放进次要入口。
- **少用弹窗**。选择数量、确认提交等直接放在页面里；只有删除这类不可撤销的操作才弹窗确认。
- **同一套响应式布局**。手机竖屏、平板横竖屏都可用。
- **视觉风格**。系统字体，浅色背景，一种主色（"晴空"蓝 `#1f6feb`）；不用渐变、阴影堆叠和装饰图案。颜色、字号、间距只在 `src/styles/tokens.css` 中定义。

## 技术方案

- **界面**：React + TypeScript + Vite。不引入状态管理库和路由库；页面切换用一个简单的页面栈，同时处理 Android 返回键。
- **Android 外壳**：Capacitor 8，只做 Android。
- **原生能力**：

| 能力 | 实现 |
|---|---|
| 朗读 | `@capacitor-community/text-to-speech`，底层是系统 TTS |
| 拍照、选图 | `@capacitor/camera`；裁剪用 Cropper.js，缩放和压缩用 Canvas |
| 屏幕常亮 | `@capacitor-community/keep-awake` |
| 返回键 | `@capacitor/app` |
| 数据文件 | 自写的 SAF 存储插件（Java，`android/app/src/main/java/com/smartstudy/SafFolderPlugin.java`），见架构决定 002 |
| API Key、草稿 | `@capacitor/preferences`，只存在 App 私有目录 |

- **模型调用**：用 fetch 直接调用 DashScope 的 OpenAI 兼容接口，不用 SDK。该接口允许浏览器跨域调用，所以电脑和 App 用同一份代码。
- **分层**：页面组件只调用 `src/services/`、`src/storage/` 和 `src/ai/` 里的接口；朗读、拍照、存储、模型调用在 App、浏览器和测试里各有实现。业务规则（抽样、统计、解析、数据校验、划线标记）放在不依赖界面的纯函数模块 `src/domain/` 和 `src/data/` 里。

## 在电脑上运行

`npm run dev` 后用 Chrome 或 Edge 打开 `http://127.0.0.1:5173`，可以完整使用：

| 能力 | 电脑上的实现 |
|---|---|
| 数据文件 | 浏览器的文件夹访问接口（File System Access API）。选一个本地文件夹，例如从平板拷出来的 `smartstudy` 副本，文件格式和手机完全相同 |
| 拍照 | 从电脑选图片文件 |
| 朗读 | 浏览器自带的语音合成（Windows 上有中文语音） |
| 模型调用 | 直接调用 DashScope，API Key 在设置页填写 |

自动测试使用假的朗读和模型服务，不调用 DashScope，也不产生费用。

## 千问模型与 API Key

| 用途 | 默认模型 | 价格（华北2，每百万 Token，输入 / 输出） | 说明 |
|---|---|---|---|
| 识别听写词语、识别错题、识别划线 | `qwen3.8-flash` | 0.8 元 / 2.7 元 | 图片压成最长边 1280px 的 JPEG（质量 80），一张约 1,400 Token |
| 英文翻译 | `qwen3.8-flash` | 同上 | 一个词约 70 Token |
| 举一反三 | `qwen3.8-max`，temperature 1.2 | 12 元 / 36 元 | 一道题约 400 Token |

2026-10-31 选型：
- **测了什么**：用这个 App 的真实任务，对 Qwen 3.5–3.8 各档模型逐一实测：识别带拼音和页码干扰的语文词语表；识别带孩子错误答案和划线的英语试卷并给出正确答案；翻译短语；举一反三出题。
- **结果**：
  - `qwen3.8-flash` 是最新一代里最便宜的一档，识别、答案、翻译全部正确，单次 0.7–1.6 秒。Plus 档（`qwen3.7-plus`，2 元 / 8 元）结果相同，但价格是它的 2.5–3 倍。
  - 举一反三需要出题者自己判断答案。`qwen3.8-max` 出的题都对，答案也对；一道题约 400 Token，按上表价格约 0.5–1.5 分钱，用量很小，所以选最强的一档。
  - 识别划线时只让模型列出画线的单词和字母，由代码在原文里加标记，题目原文不会被改动。两张试卷图共 10 处划线，跑了 3 次，每次全部标对，用时 2–7 秒。让模型把整道题逐字母重写的做法，同样的图只标对 3–9 处，还会丢掉单词之间的空格。
- **用量估算**：每天拍 2 张、翻译 20 个词、举一反三 10 道题，每月约 1.5–4.5 元，几乎都是举一反三（每月约 300 道题）；拍照和翻译合计每月不到 0.2 元。

调用时关闭深度思考（`enable_thinking: false`）：Qwen 3.5 以后的模型默认会先"思考"，识别和翻译这类简单任务会因此慢 5–20 倍，而结果没有改善。

模型名称、单次超时（45 秒）和重试次数可在设置里修改。提示词的默认值只在代码里保留一份；设置页可以逐条覆盖，也可以恢复默认。

API Key 在 App 设置页填写，只保存在本机 App 私有存储里，不写进代码、APK 或 `Documents/smartstudy`。仓库可以开源，每个人用自己的 Key。重装 App 后需要重新填一次 Key。

## 测试

- **Vitest**：抽样、统计、模型输出解析、划线标记、数据校验、存储和缓存，这些规则必须有单元测试。
- **Playwright**：在电脑浏览器上用平板（1280×800）和手机（412×915）两种尺寸跑完整流程，朗读和模型调用使用假实现。
- **Android 模拟器**：`tools/smoke_android.mjs` 验证授权文件夹、读写、卸载重装后数据仍在。
- **真机**：朗读时序、相机、文件夹授权和卸载重装只能在真机上验证。真机上只用测试账号，测试前后核对真实账号的文件没有变化。

2026-10-31 的结果：Vitest 124 项、Playwright 32 项全部通过；模拟器冒烟测试通过；MatePad 11 上听写、错题本、学习记录、返回键和断网使用都已验证。
